# Supplementary material

This directory contains the supplementary material for **From Revised Supervision to Deployable Forecasts: Student Responses and Delayed Transfer in Equity Prediction**.

- `supplement.pdf`: complete derivations, implementation protocol, comparison families and additional figures.
- `supplement_latex.zip`: flat, independently compilable LaTeX source package. Extract it and compile `supplement.tex` twice with pdfLaTeX.

The supplementary document refers to the main manuscript. For local cross-PDF links, put `main.pdf` next to `supplement.pdf`.

The source archive uses the official, unchanged `crorr.cls` from the [Croatian Operational Research Review template](https://hdoi.hr/crorr-journal/wp-content/uploads/2024/12/CRORR_paper_template_2024_LaTeX.zip). Its original terms and comments are retained; the repository's MIT code license does not relicense this class file.
